# 角色衣橱 look：正文 `@[角色@look]` 选型，默认基准

参考生视频靠资产图锚定静态外观，正文禁止另写外貌；一时一事的「脸蹭血」不该进角色库，但跨多镜复用的换装 / 大战损又需要可切换的 sheet。平行假角色（`林北受伤`）能用但音色与身份断裂；unit 上另存 `look_bindings[]` 会与「正文唯一真相」（ADR 0064）分叉。决定：角色下挂少量 **look**（必须有且仅有一个 `base`，其余自由命名）；书写层 `@[角色]` 取基准、`@[角色@look]` 取指定 look；未写 look 默认基准。LLM 只在已登记 look 里建议，人改正文即可换绑或退回基准。参考生视频每集拆 unit 前须完成本集资产完备审查（`propose_character_looks`）：登记会跨镜复用的换装 / 大战损，以及本集会 `@` 引用且库中尚无的场景 / 道具（写入 `project.json` 共用资产表，后续缺图走 `generate_asset_sheets`）；瞬时妆伤不进衣橱，路过一笔的地点/物件不登记。非 base 的 sheet 以 base 图为参考衍生；文件名为 `characters/{名}__{look}.png`。分镜路线本轮仍只用基准 sheet。
